## Reflection Questions

### 1. What surprised you most about how the widget tree, state, or lifecycle actually behaves once you saw it applied in the app?

What surprised me was how everything in Flutter is connected through the widget tree. At first, I thought changing one widget would only affect that widget, but I realized that the parent and child widgets work together. I also understood better why initState() and dispose() are needed when using a controller.

### 2. Which concept took the longest to click for you, and what finally made it make sense?

The Widget Tree and Stateful vs. Stateless widgets took me the longest to understand. It started making more sense when I actually changed the tabs and saw the UI update. Seeing the TabController keep track of the selected tab helped me understand why state is needed.

### 3. What part of the GitHub workflow felt least familiar, and how did you work through it?

The GitHub part was probably the least familiar to me, especially setting up the repository and pushing my project from VS Code. I had some problems with Git asking for my name and email. I looked at the error message, fixed the Git configuration, and then was able to commit and push my code.

### 4. If you rebuilt this activity from scratch tomorrow, what would you do differently?

I would plan the structure of the app before starting. I would also make the changes one task at a time and test after each change. This would make it easier to find where an error came from instead of changing many things at once.
